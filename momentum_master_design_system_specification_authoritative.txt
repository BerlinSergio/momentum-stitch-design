# Momentum Application: Master Design System Specification
**Version 2.0.0 — Final & Authoritative Production Reference for Flutter Implementation**
*Derived strictly from the 38 Approved Momentum Pages (76 UI Screens across Light Mode & Dark Mode) and the 30-Scene Atmospheric Wallpaper System.*

---

## 1. Executive Vision & Core Architectural Model

**Momentum** is an intentional, offline-first personal productivity, halal-conscious daily lifestyle, and personal finance mobile application designed for serenity, clarity, and mindful focus. It harmoniously bridges daily civil commitments, habit tracking, personal bookkeeping, reflective journaling, and sacred spiritual routines (prayer timings, tri-calendar confluence, and tasbeeh) within an atmospheric, translucent mobile canvas.

### 1.1 Inviolable Product & Architectural Boundaries
1. **Local-First & Zero-Knowledge Sanctuary:**
   - **No Login / No Cloud Account / No Firebase:** The app operates completely locally on the device without registration, email capture, or third-party cloud auth.
   - **Zero Analytics / No Tracking:** Personal reflections, daily habits, and financial logs reside entirely within on-device encrypted local storage.
2. **Generic Hardware-Agnostic Biometrics:**
   - Use the generic term **Biometric Authentication** across all UI labels and settings.
   - Strictly forbidden: vendor-specific trademarks (such as Face ID, Touch ID, Android Biometric Prompt v3).
3. **No Financial Charts or Zakat Calculators:**
   - Personal finance focuses on straightforward, scannable clarity: balances, income vs. expense transactions, categories, transaction notes, search, filtering, and simple numerical progress targets.
   - Strictly forbidden: pie charts, sparklines, circular donut charts, or unapproved Zakat quota calculators.
4. **Standardized Locale & Astronomical Simplicity:**
   - Standard city selection is a clean, searchable list of cities with country context.
   - Strictly forbidden: requirements for live GPS sensor tracking, coordinate geocoding (latitude/longitude), or elevation (MSL) meters in UI.
   - Fixed default locale:
     - **Default Currency:** `AFN / ؋` (Afghan Afghani)
     - **Default Timezone:** `Asia/Kabul` (UTC+4:30)
     - **Default City:** `Kabul, Afghanistan`
5. **Atmospheric Glassmorphism & Translucency:**
   - Interfaces float gracefully above curated serene backgrounds using multi-layer backdrop blurs, subtle border highlights, and controlled opacity levels.
6. **Zero-Drift 1:1 Light & Dark Parity:**
   - Light Mode and Dark Mode screens share identical layouts, component dimensions, typography scales, padding, and information architecture. Only surface tokens, text colors, and backdrop lighting shift.
7. **Calm Ergonomics & Fixed Centered Navigation:**
   - Bottom-anchored interactions, consistent 48px touch targets, balanced vertical cadence, and a physically centered primary action trigger (`+`).

## 4. Elevation, Radii & Glassmorphism System

### 4.1 Border Radii
- **`rounded-full` (9999px):** Primary circular action button (`+`), category pills, indicator dots, toggle thumbs.
- **`rounded-2xl` (20px–24px):** Primary hero cards, live preview simulators, large modal bottom-sheets, wallpaper library hero.
- **`rounded-xl` (14px–16px):** Standard list cards, input fields, search inputs, calendar day blocks, quick action containers.
- **`rounded-lg` (8px–10px):** Small badges, notification offset chips, numeric keypad keys, secondary buttons.
- **`rounded-md` (6px):** Checkboxes, radio inner pips, micro tags.

### 4.2 Shadows & Lighting Effects
- **Floating Card Depth (Light Mode):** `box-shadow: 0 10px 25px -5px rgba(79, 107, 255, 0.08), 0 8px 10px -6px rgba(0, 0, 0, 0.03)`
- **Floating Card Depth (Dark Mode):** `box-shadow: 0 10px 30px -5px rgba(0, 0, 0, 0.50), 0 0 1px 1px rgba(255, 255, 255, 0.06)`
- **Center Action Button Glow (`+`):**
  - *Light Mode:* `box-shadow: 0 12px 24px -4px rgba(79, 107, 255, 0.45)`
  - *Dark Mode:* `box-shadow: 0 12px 28px -4px rgba(99, 102, 241, 0.55), 0 0 15px rgba(56, 189, 248, 0.35)`
- **Inner Rim Highlight:** `border-top: 1px solid rgba(255, 255, 255, 0.40)` (simulates refractive top edge in glass).

### 4.3 Backdrop Blur Hierarchy
- **`backdrop-blur-none` (0px):** Raw background visibility.
- **`backdrop-blur-sm` (4px–8px):** Subtle scrims and secondary tooltips.
- **`backdrop-blur-md` (12px–16px):** Standard list rows, secondary cards, search bars.
- **`backdrop-blur-xl` (20px–24px):** Primary hero containers, main bottom navigation dock, sticky top app bars, modals.
- **`backdrop-blur-2xl` (32px–40px):** Deep focus overlays, PIN lock shield screens.

## 5. Layout Grid & Spacing System

### 5.1 Base 4px Grid Rhythm
All padding, margin, height, and spacing values derive strictly from multiples of 4px:
- `2px` (0.5 unit): Hairline borders, micro gaps.
- `4px` (1 unit): Icon-to-label spacing, badge inner padding.
- `8px` (2 units): Compact row spacing, tag gaps, sub-element separation.
- `12px` (3 units): Standard internal card padding (mobile compact), input inset padding.
- `16px` (4 units): Standard screen container horizontal margin, standard card padding, stack gaps.
- `20px` (5 units): Hero card padding, major section vertical spacing.
- `24px` (6 units): Section-to-section separation rhythm.
- `32px` (8 units): Major structural dividers, onboarding header offsets.
- `48px` (12 units): Standard touch target minimum dimension (buttons, row items).
- `84px` (21 units): Total bottom clearance padding to guarantee zero overlap with the persistent dock.

### 5.2 Mobile Viewport Geometry
- Target Reference Width: 390px–412px (Adaptive fluid 100% max 440px centered).
- Target Viewport Height: ~844px–915px.
- Screen Horizontal Gutter: 16px.

## 6. App Chrome & Navigation Architecture

### 6.1 Main Bottom Navigation Dock (Tab Chrome)
*Present on: Home Dashboard, Finance Tracker, Tasks & Reminders, Calendars Main, Notes Main, Tasbeeh Main, Prayer Times, Settings & Profile.*

```
+-----------------------------------------------------------------------+
|  [Home]       [Finance]        ( + )        [Tasks]         [More]    |
|   icon          icon          FLOATING       icon            icon     |
|   label         label          ACTION        label           label    |
+-----------------------------------------------------------------------+
```

1. **Slots & Ordering:** Strictly 5 slots in fixed order:
   `Home` (Index 1) | `Finance` (Index 2) | `+` (Center Trigger) | `Tasks` (Index 4) | `More` (Index 5)
2. **Physical Centering of `+` (INVIOLABLE INVARIANT):**
   - The `+` button is placed inside a dedicated flex center container (`flex-1 flex justify-center items-center`) that guarantees mathematical horizontal centering irrespective of viewport width or active tab.
   - **Dimensions:** 52px × 52px circular medallion.
   - **Elevation:** Floats -14px above the top rim of the dock with radiant gradient wash.
   - **Icon:** 24px bold plus icon (`+`), centered with crisp optical balance.
3. **Tab Item Specs:**
   - Inactive: 22px outline icon, 10px label text, Slate 500 (`#64748b`).
   - Active: 22px filled/emphasized icon, 10px medium label text, theme primary (`#4f6bff` Light / `#818cf8` Dark) with subtle bottom indicator dot or pill glow.
4. **Dock Bar Enclosure:**
   - Height: 68px + bottom safe-area padding (~16px). Total: ~84px.
   - Floating Margins: 12px horizontal margin, rounded-3xl (`28px`), `backdrop-blur-xl`.

### 6.2 Focused Top Navigation (Stack Chrome)
*Present on: Sub-pages, Add/Edit Forms, Category Selectors, About Momentum, Settings detail pages.*
- **Container Height:** 56px.
- **Left Slot:** 40px × 40px circular tap target with 20px back chevron (`←`), restoring previous state with smooth pop transition.
- **Center Slot:** Screen title, 17px–18px font-semibold Space Grotesk/Inter, centered with optical truncation for long titles.
- **Right Slot:** Context action (e.g., Save text button, reset trigger, or info icon). If no action exists, an empty 40px balancer retains title centering.

## 7. Component Library Standardization

### 7.1 Cards & Containers
1. **Hero / Metric Card:**
   - Padding: 18px–20px.
   - Border radius: `rounded-2xl` (20px).
   - Features: Atmospheric gradient wash, status badge, large metric numeral, simple progress bar. (No charts or sparklines).
2. **Grouped Settings Card:**
   - Container wrapping multiple settings rows with 1px divider lines (`rgba(0,0,0,0.04)` Light / `rgba(255,255,255,0.05)` Dark).
   - Inset row padding: 14px horizontal, 14px vertical.
   - Right-side accessories: Chevron (`>`), toggle switch, or current value label.
3. **Interactive List Card:**
   - Padding: 14px–16px.
   - Border radius: `rounded-xl` (16px).
   - Hover / Active state: 2% lighter background, subtle active border highlight.

### 7.2 Buttons & Action Triggers
1. **Primary Action Button (`.btn-primary`):**
   - Height: 48px–52px. Full width or dock width.
   - Geometry: `rounded-xl` (14px) or `rounded-full`.
   - Gradient: Theme Indigo gradient.
   - Text: 15px font-semibold, white (`#ffffff`), centered with optional trailing arrow (`→`).
   - State: Active press scales down by 1.5% (`scale(0.985)`).
2. **Secondary / Outlined Button (`.btn-secondary`):**
   - Height: 48px.
   - Surface: Frosted white (`rgba(255, 255, 255, 0.60)`) / Dark slate (`rgba(30, 38, 54, 0.60)`).
   - Border: 1px solid theme primary or border hairline.
   - Text: 14px font-medium theme primary or text-primary.
3. **Tertiary / Destructive Button (`.btn-danger`):**
   - Surface: `rgba(239, 68, 68, 0.12)`.
   - Text: `#ef4444` (Light) / `#f87171` (Dark).

### 7.3 Form Inputs & Search Fields
1. **Standard Text Input:**
   - Height: 48px.
   - Border radius: `rounded-xl` (14px).
   - Inset: 14px horizontal, leading icon 20px from left.
   - Surface: `rgba(255, 255, 255, 0.70)` (Light) / `rgba(16, 23, 35, 0.70)` (Dark).
   - Border: 1px solid hairline; on focus: 2px solid theme primary + soft ring glow.
   - Placeholder Text: Slate 400 (`#94a3b8`).
2. **Search Bar:**
   - Height: 44px.
   - Surface: Frosted container with leading magnifying glass icon and trailing clear `✕` button when active.
   - Filter Chips Row: Horizontal scrolling row of pill buttons (`rounded-full`) directly below search bar.

### 7.4 Toggles & Segmented Controls
1. **Toggle Switch:**
   - Track Dimensions: 48px width × 28px height.
   - Thumb Diameter: 22px circle with soft drop shadow.
   - Off State: Slate 300 track (`#cbd5e1`) Light / Slate 700 track (`#334155`) Dark.
   - On State: Primary Indigo gradient track with white thumb translated 20px right.
2. **Segmented Multi-Choice (e.g., Light / Dark / System):**
   - Height: 40px.
   - Outer container: `rounded-full`, 4px internal padding.
   - Active Segment: Pill surface with subtle shadow and primary text color.
   - Inactive Segment: Transparent with secondary text color.

### 7.5 Security PIN Pad & Biometrics
1. **Masked PIN Indicator:**
   - 4 discrete circular slots (16px diameter).
   - Empty slot: 2px border ring (`rgba(255, 255, 255, 0.30)` or Slate 300).
   - Filled slot: Solid primary indigo fill (`••••`).
   - Active slot: Blinking border pulse.
   - Plaintext values are strictly forbidden in UI and DOM.
2. **Numeric Keypad (3×4 Grid):**
   - Keys 1–9, `Clear`, `0`, Backspace.
   - Key Dimensions: Minimum 56px height, `rounded-xl`, high contrast numeral with secondary alpha letters (ABC, DEF).
   - Haptic Feedback / Active state: Frosted button depress visual state.
3. **Biometric Authentication:**
   - Described strictly as generic **Biometric Authentication** across all labels, dialogs, and toggles.

### 7.6 Selection Controls (Radio & Checkbox)
1. **Checkbox:**
   - 22px × 22px, `rounded-md` (6px).
   - Checked: Primary indigo gradient with crisp white checkmark SVG.
2. **Radio Pip:**
   - 22px outer circle, 10px inner solid pip when selected.

## 8. Atmospheric Wallpaper & Blur System

### 8.1 30-Scene Paired Architecture (60 Variants Total)
Momentum features an engineered collection of 30 scenic environments organized into 4 distinct categories:
1. **Atmospheric Skies (01–06):** Dawn Tranquility, Serene Horizon, Twilight Cloudscape, Aurora Solitude, Dusk Radiance, High Noon Mist.
2. **Minarets & Heritage (07–14):** Minaret Sunrise, Sacred Geometry, Blue Mosque Dusk, Archway Reflections, Andalusian Courtyard, Samarkand Azure, Palm Oasis Silhouette, Desert Minaret.
3. **Calm Nature & Solitude (15–22):** Kabul Solitude, Emerald Oasis, Mountain Zenith, Quiet Pine Mist, Alpine Reflection, Dune Silence, Cascading Spring, Cedar Grove.
4. **Abstract Glass & Refraction (23–30):** Lavender Haze, Prismatic Fluid, Indigo Silk, Radiant Sphere, Amber Quartz, Obsidian Refraction, Luminous Void, Opal Ribbon.

### 8.2 Light & Dark Pairing Rules
- Every scene has an exact **Light Mode variant** and **Dark Mode variant** sharing the same physical subject and composition (30 scenes × 2 themes = **60 background variants**).
- The Light variant provides luminous daylight or golden sunrise illumination.
- The Dark variant converts the scene into twilight, nocturnal moonlight, or starry obsidian tones without moving landscape elements.
- Wallpapers must never contain baked-in text, simulated widgets, mock phones, or buttons.

### 8.3 Precision Blur Calibration Scale

| Blur Preset | Pixel Radius | Scrim Compensation | Recommended Usability Case |
|---|---|---|---|
| **Crisp** | `0px` | +15% dark/light scrim | Maximum scenery visibility; card backdrops handle legibility |
| **Subtle** | `8px` | +10% scrim | Softens sharp photographic edges while retaining landscape forms |
| **Soft (Standard)** | `18px` | Default (0% offset) | **Official Momentum Default.** Perfect balance of depth and contrast |
| **Deep** | `28px` | -5% scrim | Abstracted colors, emphasizes floating card elevation |
| **Dreamy** | `40px` | -10% scrim | Pure chromatic aura gradient wash; lowest visual distraction at night |

### 8.4 Wallpaper System Operation
- **Default / Offline Collection:** High-resolution assets packaged locally with the app for full offline functionality.
- **Daily Rotation:** Optional daily cycle through the collection aligned to daylight hours.
- **Online Update Concept:** Ability to download future seasonal scenic packs into local storage without requiring app redeployment.
- **Content Readability Guardrails:**
  - Card surfaces never drop below 70% opacity over wallpapers.
  - Header scrim dynamically applies `backdrop-blur-xl` and a 15% gradient scrim during scroll.

## 9. State Conventions & Interaction Micro-Patterns

1. **Active / Pressed State:**
   - Clickable cards and buttons apply `transform: scale(0.985)` with a 150ms ease-out curve.
2. **Selected State:**
   - Checked list items (cities, timezones, currencies) feature a solid filled badge with checkmark (`✓`) and a 1.5px primary border ring around the entire container row.
3. **Empty States:**
   - Friendly, serene icon (peaceful leaf, empty inbox outline, or crescent), concise heading (*"No transactions yet"*), and one clear primary action button (*"Record First Expense"*).
4. **Loading & Skeleton States:**
   - Translucent shimmer cards with soft horizontal sweep gradient:
     `linear-gradient(90deg, rgba(255,255,255,0) 0%, rgba(255,255,255,0.15) 50%, rgba(255,255,255,0) 100%)`.
